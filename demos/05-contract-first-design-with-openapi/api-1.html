Get historical daily OHLCV candles

One row per trading day. Each candle carries the raw close as traded and adjclose restated for splits and dividends — use adjclose for returns. Rows Fauxnance generated to bridge an upstream gap are flagged synthetic: true.

Authorizations:
ApiKeyAuth
path Parameters
symbol
required
string [ 1 .. 32 ] characters
Examples:
  • AAPL -
  • INFY.NS -
  • FX:EURUSD -
  • X:BTC-USD -

Case-insensitive Fauxnance symbol; responses use uppercase.

query Parameters
from
string <date>
Example: from=2026-01-01

Inclusive start date; defaults to one year before to. The range from from to to may not exceed ten years.

to
string <date>
Example: to=2026-08-26

Inclusive end date; defaults to today.

interval
string
Default: "1d"
Value: "1d"

The period one candle covers. Version 1 serves daily candles only, so 1d is the sole accepted value and anything else is a VALIDATION_ERROR; 1wk and 1mo are planned. Equities, ETFs and FX return eligible weekdays, crypto returns UTC calendar days.

Responses

Deployed dev API Gateway endpoint; no custom domain is configured.
